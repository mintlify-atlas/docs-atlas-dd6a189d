The admin sales endpoints give administrators full visibility into every order placed through VinylVibes. Admins can list all sales across all users, inspect individual order details including line items and shipping addresses, and move orders through their lifecycle from `pendiente` to `entregado`. All three endpoints require a valid JWT from an account with the `admin` role.

---

## GET /admin/ventas

**Authentication:** Required — admin JWT

Returns all orders across all users. This is the data source for the admin panel's sales table, the pending-orders stat card, and the total revenue calculation.

### cURL Example

```bash
curl https://api-tienda-vinilos.onrender.com/admin/ventas \
  -H 'Authorization: Bearer <admin_token>'
```

### Response

Returns an array of order summary objects.

<ResponseField name="id" type="integer">
  Unique order ID.
</ResponseField>

<ResponseField name="nombre_usuario" type="string">
  Username of the buyer who placed the order.
</ResponseField>

<ResponseField name="estado" type="string">
  Current order status. One of: `pendiente`, `enviado`, `entregado`, or `cancelado`.
</ResponseField>

<ResponseField name="total" type="string">
  Order total as a decimal string (e.g., `"89.97"`).
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the order was placed.
</ResponseField>

### Response Example

```json
[
  {
    "id": 42,
    "nombre_usuario": "cliente_123",
    "estado": "pendiente",
    "total": "89.97",
    "created_at": "2025-05-20T14:23:00Z"
  }
]
```

## GET /admin/ventas/\{id\}

**Authentication:** Required — admin JWT

Returns the full detail for a single order, including its complete list of purchased vinyl records and the shipping address provided at checkout. The admin panel calls this endpoint when an admin clicks "Ver detalle" in the sales table.

### Path Parameter

| Parameter | Type    | Description  |
|-----------|---------|--------------|
| `id`      | integer | Order ID     |

### cURL Example

```bash
curl https://api-tienda-vinilos.onrender.com/admin/ventas/42 \
  -H 'Authorization: Bearer <admin_token>'
```

### Response

<ResponseField name="id" type="integer">
  Unique order ID.
</ResponseField>

<ResponseField name="nombre_usuario" type="string">
  Buyer's username.
</ResponseField>

<ResponseField name="estado" type="string">
  Current order status.
</ResponseField>

<ResponseField name="total" type="string">
  Order total as a decimal string.
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 creation timestamp.
</ResponseField>

<ResponseField name="items" type="array">
  Array of vinyl records included in the order.

  <Expandable title="Item fields">
    <ResponseField name="discogs_id" type="string">
      Discogs release ID.
    </ResponseField>
    <ResponseField name="titulo" type="string">
      Album title.
    </ResponseField>
    <ResponseField name="artista" type="string">
      Artist name.
    </ResponseField>
    <ResponseField name="precio" type="number">
      Unit price at the time of purchase.
    </ResponseField>
    <ResponseField name="cantidad" type="integer">
      Quantity ordered.
    </ResponseField>
  </Expandable>
</ResponseField>

<ResponseField name="envio" type="object">
  Shipping address provided at checkout.

  <Expandable title="Shipping address fields">
    <ResponseField name="nombre" type="string">
      Recipient's full name.
    </ResponseField>
    <ResponseField name="calle" type="string">
      Street name.
    </ResponseField>
    <ResponseField name="num_ext" type="string">
      Exterior number.
    </ResponseField>
    <ResponseField name="num_int" type="string">
      Interior number (if provided).
    </ResponseField>
    <ResponseField name="colonia" type="string">
      Neighborhood.
    </ResponseField>
    <ResponseField name="cp" type="string">
      Postal code.
    </ResponseField>
    <ResponseField name="ciudad" type="string">
      City.
    </ResponseField>
    <ResponseField name="estado" type="string">
      State or region.
    </ResponseField>
    <ResponseField name="referencias" type="string">
      Delivery references (if provided).
    </ResponseField>
  </Expandable>
</ResponseField>

## PUT /admin/ventas/\{id\}/estado

**Authentication:** Required — admin JWT

Updates the status of a specific order. Status changes take effect immediately and are visible to the buyer in `GET /mis-compras`. The admin panel triggers a client-side list refresh after a successful update, without a full page reload.

### Path Parameter

| Parameter | Type    | Description  |
|-----------|---------|--------------|
| `id`      | integer | Order ID     |

### Request Body

<ParamField body="estado" type="string" required>
  The new status to assign. Must be one of: `pendiente`, `enviado`, `entregado`, `cancelado`.
</ParamField>

### cURL Example

```bash
curl -X PUT https://api-tienda-vinilos.onrender.com/admin/ventas/42/estado \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <admin_token>' \
  -d '{"estado": "enviado"}'
```

### Success Response (200)

```json
{ "message": "Estado actualizado" }
```

### Order Status Lifecycle

| Status      | Description                                  |
|-------------|----------------------------------------------|
| `pendiente` | Order placed, awaiting processing            |
| `enviado`   | Order shipped                                |
| `entregado` | Order delivered to customer                  |
| `cancelado` | Order cancelled                              |

<Tip>
  The admin panel frontend renders a colored badge for each status value in the sales table. After calling this endpoint successfully, the panel updates the stats cards (including the pending-orders count) in real time without a full page reload.
</Tip>
