VinylVibes exposes two user-specific endpoints for tracking purchase activity. `GET /mis-compras` returns the full order history for the authenticated user and is used to populate the "Mis Compras" side panel in the storefront. `POST /historial` records vinyl view events automatically when a user opens an album's detail modal, and these events are used by the backend to power personalized recommendations via `GET /disco/{id}/recomendaciones`.

---

## GET /mis-compras

**Authentication:** Required — `Authorization: Bearer <token>`

Returns the complete purchase history for the authenticated user, ordered from most to least recent. Each order includes its status, total, and a full list of the vinyl records purchased.

### cURL Example

```bash
curl https://api-tienda-vinilos.onrender.com/mis-compras \
  -H 'Authorization: Bearer <token>'
```

### Response

Returns an array of order objects.

<ResponseField name="id" type="integer">
  Unique order ID.
</ResponseField>

<ResponseField name="estado" type="string">
  Current order status. One of: `pendiente`, `enviado`, `entregado`, or `cancelado`.
</ResponseField>

<ResponseField name="total" type="string">
  Order total as a decimal string (e.g., `"59.98"`).
</ResponseField>

<ResponseField name="created_at" type="string">
  ISO 8601 timestamp of when the order was placed.
</ResponseField>

<ResponseField name="items" type="array">
  Array of vinyl records included in this order.

  <Expandable title="Item fields">
    <ResponseField name="discogs_id" type="string">
      Discogs release ID of the vinyl.
    </ResponseField>

    <ResponseField name="titulo" type="string">
      Album title at the time of purchase.
    </ResponseField>

    <ResponseField name="artista" type="string">
      Artist name at the time of purchase.
    </ResponseField>

    <ResponseField name="imagen_url" type="string">
      URL of the album cover image.
    </ResponseField>

    <ResponseField name="precio" type="number">
      Unit price at the time of purchase.
    </ResponseField>

    <ResponseField name="cantidad" type="integer">
      Quantity of this title ordered.
    </ResponseField>
  </Expandable>
</ResponseField>

### Response Example

```json
[
  {
    "id": 42,
    "estado": "enviado",
    "total": "59.98",
    "created_at": "2025-05-20T14:23:00Z",
    "items": [
      {
        "discogs_id": "12345",
        "titulo": "Kind of Blue",
        "artista": "Miles Davis",
        "imagen_url": "https://...",
        "precio": 29.99,
        "cantidad": 2
      }
    ]
  }
]
```

## POST /historial

**Authentication:** Required — `Authorization: Bearer <token>`

Records a vinyl view event for the authenticated user. This endpoint is called automatically by the frontend whenever a logged-in user opens the album detail modal. The backend uses the accumulated view history to generate personalized recommendations surfaced through `GET /disco/{id}/recomendaciones`.

### Request Body

```json
{ "discogs_id": "string" }
```

### cURL Example

```bash
curl -X POST https://api-tienda-vinilos.onrender.com/historial \
  -H 'Content-Type: application/json' \
  -H 'Authorization: Bearer <token>' \
  -d '{"discogs_id": "12345"}'
```

<Tip>
  If the user is not logged in, the frontend silently skips the `POST /historial` call entirely — no token means no request is made, and no error is surfaced to the user.
</Tip>
